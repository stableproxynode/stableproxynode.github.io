📲 Как подключить

📱 iPhone / Android ▶
  1. Скопируй ссылку выше (кнопка «копировать ссылку»)
  2. Открой Telegram
  3. Зайди в Настройки → Данные и память → Прокси
  4. Удали все прокси, что там есть
  5. Нажми Добавить прокси
  6. Разреши вставку из буфера обмена
  7. Сверху нажми «Вставить из буфера обмена» — готово ✓
💻 ПК (Windows / Mac) ▶
  1. Открой Настройки
  2. Перейди в Продвинутые настройки
  3. Найди раздел Тип соединения
  4. Выбери «Использовать собственный прокси» (MTProto)
  5. Впиши Сервер, Порт и Secret из блока выше
  6. Сохрани — готово ✓
