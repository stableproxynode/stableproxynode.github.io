# STABLE_PROXY — информационный сайт о прокси

Одностраничный сайт в терминальном / «хакерском» стиле. Публикует **актуальную ссылку
на прокси**, которая обновляется при сбоях и блокировках, рассказывает о стабильности
узла и предлагает поддержать автора донатом.

**Живой адрес:** https://stable-proxy-node.surge.sh

---

| Блок | Описание |
|------|----------|

| **Системные строки** | «Псевдо-лог» загрузки: шифрование AES-256, uptime 99.9%, логи не ведутся. |
| **Статус-бейдж** | Пульсирующий индикатор «УЗЕЛ В СЕТИ · ССЫЛКА АКТУАЛЬНА». |
| **Описание** | Текст про стабильный прокси и про то, что актуальная рабочая ссылка всегда на этой странице. |
| **Кнопка подключения** | По центру. Ссылка **спрятана**; по клику раскрывается блок с кнопками «открыть ↗» и «копировать». |
| **Поддержка автора** | Две карточки: донат на карту (с кнопкой копирования номера) и Telegram-звёзды. |

## Как обновить ссылку на прокси

Вся настройка — в **одном** месте: блок `CONFIG` в начале тега `<script>` в `index.html`.

```js
const CONFIG = {
  proxyLink: "https://t.me/proxy?server=HOST&port=PORT&secret=SECRET", // ← актуальная ссылка
  cardNumber: "",      // номер карты, напр. "2200 0000 0000 0000"
  telegramStars: "",   // "@username" или "https://t.me/username"
};
```

1. Поменяй `proxyLink` на новую рабочую ссылку.
2. Заполни `cardNumber` и `telegramStars`, когда будут данные (пока показываются заглушки).
3. Переопубликуй (см. `DEPLOY.md`).

> Карта и Telegram-звёзды появляются на сайте автоматически, как только в `CONFIG`
> вписаны непустые значения. Пока пусто — отображаются placeholder'ы.

## Технологии

- Чистый **HTML + CSS + JavaScript**, без фреймворков и сборки.
- Анимация фона — `<canvas>` (matrix rain).
- Копирование в буфер — `navigator.clipboard`.
- Хостинг — **surge.sh** (статический, бесплатный, HTTPS).
